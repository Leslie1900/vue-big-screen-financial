# 世界银行全球智慧金融数字全景大屏 (World Bank Dashboard)

基于 **Vue 2.7 + Vite + ECharts 5 + Mock.js** 打造的高保真、高交互、金融科技风大屏数据看板系统。

---

## 🌟 项目亮点与板块特性

### 1. 经典金融科技蓝视觉设计体系

- **色彩规范**：世界银行标志性深海蓝 (`#003b8e`)、科技青光蓝 (`#00f2fe`)、金融质感金 (`#ffb703`)、健康绿与预警红；
- **炫酷质感**：四角科技切角标记、发光粒子光晕、扫描线底纹、毛玻璃半透明容器面板。

### 2. 丰富完备的大屏业务板块

1. **顶部导航运营监控条**：
   - 包含世界银行品牌 Logo、核心主干网络实时在线状态与毫秒级延迟；
   - 动态实时翻牌时钟（年月日、星期、时分秒）与一键全屏切换。
2. **顶层六大核心资产与运行指标带**：
   - 资产总规模、各项存款余额、各项贷款余额、今日交易笔数、实时峰值 TPS、AI 实时风控拦截次数，支持动态微调与环比趋势标注。
3. **中央巨幕：全国分行资金清算拓扑网络飞线图**：
   - 覆盖北京、深圳、广州、香港、南京、杭州、武汉、成都等全国 16+ 核心分支机构及上海总行；
   - 飞线迁徙动画（流向上海总行数据中心）、多层光晕水波纹涟漪动效、交互 Tooltip 与底部指标徽章。
4. **24 小时交易吞吐与 TPS 趋势走势**：
   - 金额柱状图与峰值 TPS 折线图双轴联动，支持“综合双轴 / TPS 峰值 / 交易金额”一键切换。
5. **信贷资产与金融产品业务结构环形图**：
   - 涵盖普惠金融、零售消费、跨境投融资、财富管理、绿色金融五大业务生态比例与发光图例。
6. **全渠道金融服务协同画像雷达图**：
   - 手机银行、企业网银、开放 API、VTM、线下网点、云上交银的多维效能画像。
7. **重点一级分行业务综合实力排行榜**：
   - 金银铜渐变排行榜、动态进度条达成率展示。
8. **绿色金融与科技金融双轮引擎仪表盘**：
   - 弧形双仪表（科创金融增速、线上业务渗透率）+ 绿色信贷与 CO2 减排数据卡。
9. **智慧风控中台实时防御事件流**：
   - 动态模拟 AI 反洗钱、跨国异地登录、高频交易拦截的流水滚动播报（自动追加与淡出动效）。

### 3. 自适应分辨率缩放适配

- 采用 **1920×1080** 视口基准比例与 `scale` 智能等比缩放计算，无论在 2K、4K、投影拼接屏或笔记本屏幕均能完美自适应居中显示。

## 🚀 快速启动指南

### 启动本地开发服务：

```bash
npm run dev
```

启动后访问控制台输出的地址（默认 `http://localhost:3000`）。

### 项目打包构建：

```bash
npm run build
```

打包输出至 `dist/` 目录，开箱即用。

### 本地预览构建产物：

```bash
npm run preview
```
