# 大屏项目集合 (Bigscreen Projects)

本项目目录收录了 Vue 2 与 Vue 3 两个版本的大屏数据可视化系统：

---

## 📁 目录结构

```
bigscreen-projects/
├── bocom-dashboard/         # Vue 2.7 + Vite + ECharts 5 大屏系统
└── bocom-dashboard-vue3/    # Vue 3 + Vite + ECharts 5 大屏系统
```

---

## 🚀 快速启动

### 1. Vue 2 版本大屏 (bocom-dashboard)
```bash
cd bocom-dashboard
npm run dev
```

### 2. Vue 3 版本大屏 (bocom-dashboard-vue3)
```bash
cd bocom-dashboard-vue3
npm run dev
```
